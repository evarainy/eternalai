4. 这些本机文件含机器路径、配置或敏感引用，不随代码公开提交。接续时由 owner 在授权范围内准备目标机器对应配置、浏览器/驱动路径、服务与证书；秘密只通过既有受保护入口配置。不能把本文件当作取密、修改系统、迁移数据库或部署授权。

7. 先验收 OA 只读、固定 MCP 查询和文档问答，再由用户发起一条新的 D 填写任务，核对填写后停止、字段结果、自动关闭/释放及随后再次调用。继续保持不保存、不提交。
