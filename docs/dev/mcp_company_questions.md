## 逐工具输出签收模板

恢复期限须另列可信来源：本地确认 TTL 不代表业务制品或任务资格期限。请为两个 submit 与 `talk_task_claim` 提供原制品/任务仍有效的可核验依据；未知期限不会被视为无限有效，过期后的只读核对与再次发送分别判定。前置确认许可由 `McpSubmitPreconditionPort` 承接，不能只提供 outputSchema 或成功后态规则。

为下列每个工具各提供一份版本化脱敏文件：`business_context_get`、`person_find`、`talk_context_get`、`clothing_options_get`、`clothing_result_get`、`talk_record_get`、`talk_tasks_list`、`clothing_plan_preview`、`clothing_plan_submit`、`talk_preparation_save`、`talk_record_draft_save`、`talk_record_submit`、`talk_task_claim`。

| 项 | 公司填写要求 |
|---|---|
| 身份与版本 | tool、固定服务标识、协议版本、合同版本、批准人及日期；不填写 token 或真实人员正文 |
| JSON Schema | 每字段类型、required、可空性、枚举、长度、additionalProperties；structuredContent 与 text 是否必须完全一致 |
| 权限 | 本人/他人、部门、FORBIDDEN / EMPTY / TRUNCATED / UNAVAILABLE 的准确差异；分页完整性 |
| 分用途投影 | model_fields、ui_fields、persistence_fields，逐字段给允许理由；默认不包含未列字段 |
| 成功判据 | 可确定后态及其字段；写回执、计次、发放等不同业务事实分别定义 |
| 确认与恢复 | review URL 固定来源、本人确认凭据、原制品 ID/hash/version/期限、允许与禁止的重放 |
| 最小样例集 | 正常、空、受限、截断、业务拒绝、已过期、已提交、UNKNOWN、同主体重授权；全部合成或公司确认已脱敏 |
| 签收与复验 | 责任人、批准版本、证据位置、对应回归用例；未签收标“待确认” |

基础开发插口可直接承接以上结果；重大公共合同、提供方新接口或 schema 变化另走批准流程。工程诊断事件与工具限制另列工程验收文件，不要求公司为本地开发工具事件背书。
