## 目标（done_when）

1. Gateway 返回 `denied` 时，当前 step 无产出，Workflow 以 `denied` 终止，后续 step 不再调用 Gateway。
2. Gateway 返回 `waiting_user` 时，当前 step 无产出，Workflow 以 `waiting_confirm` 终止，后续 step 不再调用 Gateway。
3. Gateway 返回 `completed` 时保持线性继续；`failed` 与 `timeout` 仍抛错，留给 P1-B4-004。
4. `WorkflowRunResult` 明示 `completed / denied / waiting_confirm` 终态；Runtime 分别映射为 `completed / denied / waiting_user`，复用既有 deny 与 confirm envelope builder。
5. Policy 决策与 Policy trace 仍只由 Gateway 负责；engine 仅在既有 Workflow/step 状态事件中记录安全终态，不写入输入、输出或敏感值。
