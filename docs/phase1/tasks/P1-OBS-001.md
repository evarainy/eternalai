## Terminal outcome matrix

| ExecutionStatus/path | Required terminal outcome |
| --- | --- |
| `completed` | exactly one `task_completed` |
| `waiting_user` | neither `task_completed` nor `task_failed` |
| `denied`, `binding_required`, `timeout`, `failed`, `no_capability_found`, structured-output parse failure | exactly one `task_failed` |

In terminal cases the outcome follows `response_envelope_created` and is the last semantic Trace event. The marker remains `[REDACTED]`. Tests use obviously synthetic values only and never place a raw sentinel in persisted/logged/reviewed evidence.
