# Monitor 独立动态取证模板

Goal 明确启用 Monitor 时，按 [AGENTS.md 的独立证据规则](../../AGENTS.md#业务-review-与明确要求的独立证据) 选取获准的动态验证。现役分工见 [11-19 裁决](DECISIONS.md#2026-11-19--裁决开发助手分工型号更新与常设授权)。历史模板见[归档](archive/MONITOR_PROMPT_TEMPLATE_to_20261119.md)。

## 派发输入

- Goal、task_id、轮次、期望合同和需动态证明的事实。提示词与结果放 AGENTS.md 指定的仓库外证据根，派发时给出精确路径。
- 目标工作树、分支、最终 base/head、需区分的候选未提交 diff 和事前工作区基线。已有验证或自审只在适用时附入。
- 具体环境、支持的入口、授权动作、禁止路径和停止条件。按 [AGENTS.md 项目不变量与红线](../../AGENTS.md#项目不变量与红线) 保护凭证、脱敏证据和原始素材。
- 主控随派发提供仓库 AGENTS.md 的实际路径、八条现役工作约定及最新用户边界。

## 可选取证方法

按本 Goal 的风险与证据缺口选取。笼统的静态比对由静态审核承担。

| 方法 | 可证明的事实 |
|---|---|
| 变异与故障注入 | 保留原检查，仅按授权改动相关生产路径，观察对应断言并恢复；核实受影响门禁的实际接线 |
| 动态授权反证 | 在获准真实路径上检查主体、资源、状态及动作边界，核对拒绝结果、隔离与副作用 |
| 测试数据充分性 | 选择能代表有效取值域和边界的获准输入，核对守卫对不同输入是否成立 |
| 依赖保真度 | 核对入口确实调用真实依赖；用脱敏日志、返回结果或获准可观测事实佐证 |
| 数字复核 | 按授权运行影响范围内的既有检查，对照同一来源和口径的基线；无对应基线时记录本次实测值 |

未授权的操作停止在对应边界。临时用例或故障注入须按当次授权；不得改 Golden fixtures 或 `FROZEN_GT_IDS`。全量仅在雨爷明确要求时执行，见 [AGENTS.md「本地测试与 required CI」](../../AGENTS.md#本地测试与-required-ci)。书面分析只能作为旁证。恢复到事前工作区基线并核对候选 base/head，保留事前已有修改，记录注入恢复情况。

## 回报

- 首行填写 `VERDICT=PASS`、`VERDICT=FAIL` 或 `VERDICT=BLOCKED`；正文附 task_id、轮次和实际 base/head。
- 对每个必需事实记录命令或操作、环境、预期、实际结果及可定位的脱敏证据。必需证据齐备且符合合同为 PASS，实测违反合同为 FAIL。因未授权或环境不可达缺必需证据时为 BLOCKED，写明缺项及受阻动作。方法无对应事实时说明原因；这不能掩盖必需证据缺项或实测失败。
- 报告恢复到事前基线的核对结果、遗留项与验证边界。修复或候选变更后按现役规则重新绑定证据。
- 同一 task_id 第三轮仍非 PASS 即停，提交雨爷裁决。中止、无结论和改写重发都计轮次，记录任务级专项裁决。
